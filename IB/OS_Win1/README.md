# Домашнее задание к занятию "ОС Windows (часть 1)`

### Задание 1
На лекции мы рассмотрели процесс загрузки ОС Windows. Ваша задача с помощью Process Explorer восстановить весь процесс загрузки (включая процедуру входа) на чистой ОС.  
В качестве результата пришлите ответы на следующие вопросы:

1. Какой процесс отображается в логе первым? Какой у него PID?
2. Какой "драйвер" загружается первым? Что это за драйвер (ответьте своими словами)?
3. Какой PID у родительского процесса для smss.exe (не у самого smss.exe, а у того, кто его создал)?
4. Какой процесс является родительским для процесса winlogon.exe? Где расположен файл winlogon.exe?
5. Какой процесс является родительским для процесса lsass.exe?
6. Что будет если в таск менеджере (taskmgr.exe) завершить работу следующего процесса: Windows Log-on Application


### Решение  

1. В логе первым отображается процесс System с PID - 4
2. Первым драйвером является PROCMON24.sys, который позволяет в реальном времени отледить весь путь загрузки системы.
3. У smss.exe Parent PID - 4, т.е. его породил первый процесс System.
4. Для процесса winlogon.exe родительским является процесс smss.exe с PID - 312. Расположение winlogon.exe - C:\Windows\System32\winlogon.exe
5. Для процесса lsass.exe родительским является процесс wininit.exe с PID - 412.
6. Завершение процесса Windows Log-on Application, т.е. winlogon.exe - завершит текущий сеанс пользователя и совершит выход из системы, закрыв все программы и завершив все запущенные пользователем процессы.
